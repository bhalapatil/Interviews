- # Different levels of questions
	- questions can be of different levels.
	- **Sanity check** these are often easy problem solving or design questions.. A minimum degree of competence in problem solving. This did not distinguish between Nokia vs great candidates. Ex: A CS graduate is expected to know basics of HTML and CSS
	- **Quality check** these are the more challenging questions opening problem solving or design. They're designed to be rigorous and really make a candidate think... They need median level of competency and algorithm and problem solving
	- **Specialist questions** these questions test specific topics such as machine learning or linear algebra or some of the courses that you might have taken as specialization or collectives.. You might be expected to have basic understanding upon these technologies and how they are used in the current industry.
